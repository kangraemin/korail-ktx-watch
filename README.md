# korail-ktx-watch

매진된 KTX의 **취소표를 자동으로 잡아 주는** 파이썬 스크립트입니다.

원하는 구간·날짜·시간대를 정해 두면 몇 초마다 빈자리를 조회하고, 자리가 나면 **바로 예약**한 뒤 알려 줍니다.
기본은 **예약까지만** 하고, 결제는 코레일톡 앱에서 직접 합니다(결제 기한 안에 안 하면 코레일이 자동 취소하고, 스크립트는 다시 감시를 이어 갑니다).
`--auto-pay`를 붙이면 `.env`에 넣어 둔 카드로 **결제·발권까지 자동**으로 합니다([자동 결제](#5-자동-결제-선택) 참고).

```
$ python ktx_watch.py --dep 부산 --arr 서울,수서 --date 20261020 --from 1700 --to 2100
로그인 성공: 홍길동
로그인 성공. 부산→서울,수서 20261020 1700~2100 출발, 어른 1명 감시 시작 (Ctrl+C로 종료)
감시 대상 9편:
  [KTX 150]  10/20 17:00~19:38  부산~서울  특실 매진, 일반실 매진 (158분)
  ...
18:02:41 #212 빈자리 없음
*** KTX 예약 성공: [KTX 158] 10/20 18:30~21:05 부산~서울 ... — 코레일톡에서 결제하세요
```

## 🤖 AI 에이전트용 설치·실행 절차

Claude Code·Codex 같은 코딩 에이전트에게 "이 레포로 KTX 취소표 잡아 줘"라고 시키면, 에이전트는 이 절을 **위에서부터 순서대로** 따르면 됩니다. 사람이 읽어도 똑같이 쓸 수 있습니다.

**0. 사용자에게 먼저 받을 것** (모르면 추측하지 말고 물어볼 것)
- 출발역, 도착역(여러 개 가능), 날짜(YYYYMMDD), 출발 시간대(HHMM~HHMM), 인원, 일반실만인지
- 결제까지 자동으로 할지(`--auto-pay`) — 기본은 예약만
- 코레일 아이디·비밀번호, 자동 결제면 카드 정보는 **사용자가 직접 `.env`에 입력**하게 한다. 에이전트는 비밀값을 채팅으로 받거나 화면·로그·커밋에 출력하지 않는다.

**1. 설치** (레포 루트에서, 한 번만)
```bash
python3 --version                      # 3.9 이상인지 확인
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp -n .env.example .env && chmod 600 .env
```

**2. `.env` 채우기** — 사용자에게 `.env`를 열어 `KORAIL_ID`, `KORAIL_PW`(필요하면 `CARD_*`, `TELEGRAM_*`)를 채우게 한다. 채웠는지는 값 출력 없이 이렇게만 확인:
```bash
grep -cE '^KORAIL_(ID|PW)=.+' .env      # 2가 나와야 함
```

**3. 점검 실행** — 예약·결제 없이 로그인과 조회만 해 본다. 실제 감시와 **같은 옵션 + `--check`**로 돌린다.
```bash
.venv/bin/python ktx_watch.py --dep 부산 --arr 서울,수서 --date 20261020 --from 1700 --to 2100 --check
```
- 성공: 마지막 줄이 `CHECK OK: ...`, 종료 코드 0 → 4로
- `로그인 실패` → 사용자에게 아이디·비밀번호 확인 요청(여러 번 재시도하지 말 것, 계정이 잠길 수 있음)
- `.env에 KORAIL_ID / KORAIL_PW를 채워 주세요` → 2로
- `--auto-pay에 필요한 .env 카드 정보가...` → 표시된 항목을 사용자가 고치게 함
- `조건에 맞는 KTX 0편` → 역 이름·날짜·시간대를 사용자와 다시 확인(역 이름은 `서울`, `부산`처럼 '역' 없이)

**4. 감시 시작** — 3과 같은 옵션에서 `--check`만 빼고 백그라운드로 돌린다.
```bash
nohup caffeinate -i .venv/bin/python -u ktx_watch.py --dep 부산 --arr 서울,수서 --date 20261020 --from 1700 --to 2100 > watch.log 2>&1 &
echo $! > watch.pid
```
(`caffeinate`는 맥 전용 — 맥이 아니면 `caffeinate -i`를 뺀다.)

**5. 상태 확인·종료**
```bash
tail -n 5 watch.log                    # '빈자리 없음'이 계속 늘면 정상 감시 중
grep -E 'KTX (예약 성공|결제 완료|자동 결제 실패|감시 종료|예약 취소됨)' watch.log
kill $(cat watch.pid)                  # 멈추기
```
- `KTX 예약 성공` → 사용자에게 알리고 코레일톡 결제를 안내(자동 결제가 아니면)
- `KTX 결제 완료` / `KTX 결제 확인` → 끝. 프로세스는 스스로 종료됨
- `KTX 자동 결제 실패` → 예약은 잡혀 있음. 사용자에게 코레일톡에서 직접 결제하라고 알림
- `KTX 감시 종료` → 시간대가 지나 못 잡음
- `오류: ... — 30초 대기`가 계속 반복 → 코레일 차단·점검 의심. 끄고 `--interval 5 8`로 다시

**하지 말 것**: `.env` 값 출력·커밋, `--interval`을 3초 아래로 줄이기, 로그인 실패 시 반복 재시도, 사용자 확인 없이 `--auto-pay` 켜기.

## 1. 준비물

- Python 3.9 이상
- 코레일 회원 계정(멤버십번호·이메일·휴대폰번호 중 하나 + 비밀번호)

## 2. 설치

```bash
git clone https://github.com/kangraemin/korail-ktx-watch.git
cd korail-ktx-watch
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 3. 계정 설정

```bash
cp .env.example .env
```

`.env`를 열어 채웁니다.

```
KORAIL_ID=1234567890          # 멤버십번호, 이메일, 휴대폰번호(010-1234-5678) 중 하나
KORAIL_PW=비밀번호

# 선택: 텔레그램으로도 알림 받기
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```

`.env`는 `.gitignore`에 들어 있어 커밋되지 않습니다.

## 4. 실행

```bash
python ktx_watch.py --dep 출발역 --arr 도착역 --date YYYYMMDD [옵션]
```

### 자주 쓰는 예

```bash
# 10월 20일 부산 → 서울 또는 수서, 17:00~21:00 출발, 1명
python ktx_watch.py --dep 부산 --arr 서울,수서 --date 20261020 --from 1700 --to 2100

# 서울 → 부산, 08:00~10:00 출발, 2명, 일반실만, 순방향 좌석
python ktx_watch.py --dep 서울 --arr 부산 --date 20261020 --from 0800 --to 1000 \
  --adults 2 --no-special --seat-dir forward

# 13:00 전에 도착하는 열차만
python ktx_watch.py --dep 서울 --arr 부산 --date 20261020 --to 1000 --arrive-before 1300
```

### 옵션

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--dep` | 출발역 (서울, 수서, 부산, 대전, 동대구 …) | 필수 |
| `--arr` | 도착역. 쉼표로 여러 개(`서울,수서`) | 필수 |
| `--date` | 출발 날짜 `YYYYMMDD` | 필수 |
| `--from` | 이 시각 **이후** 출발 `HHMM` | `0000` |
| `--to` | 이 시각 **이전** 출발 `HHMM` (포함) | `2359` |
| `--arrive-before` | 이 시각 전에 도착하는 열차만 `HHMM` | 제한 없음 |
| `--adults` | 어른 인원 | `1` |
| `--seat-dir` | 좌석 방향 `any` / `forward`(순방향) / `backward`(역방향) | `any` |
| `--no-special` | 일반실만 잡기 | 일반실 우선, 없으면 특실 |
| `--interval MIN MAX` | 조회 간격(초, 무작위) | `3 5` |
| `--auto-pay` | 예약되면 `.env`의 카드로 바로 결제 | 꺼짐(예약만) |
| `--check` | 로그인·조회 1회만 하고 종료(예약·결제 안 함). 설정 점검용 | — |

`python ktx_watch.py -h`로도 볼 수 있습니다.

## 5. 자동 결제 (선택)

예약이 잡히는 즉시 카드로 결제까지 하려면 `.env`에 카드 정보를 넣고 `--auto-pay`를 붙입니다.

```
CARD_NUMBER=1234567812345678   # 카드번호 (하이픈 있어도 됨)
CARD_PW2=12                    # 카드 비밀번호 앞 2자리
CARD_EXPIRE=2908               # 유효기간 YYMM (2029년 8월)
CARD_BIRTH=900101              # 개인카드: 생년월일 YYMMDD / 법인카드: 사업자등록번호 10자리
CARD_INSTALLMENT=0             # 할부 개월 (0 = 일시불)
```

```bash
python ktx_watch.py --dep 부산 --arr 서울 --date 20261020 --from 1700 --to 2100 --auto-pay
```

- 시작할 때 카드 정보 형식을 먼저 검사하고, 틀리면 감시를 시작하지 않습니다.
- 결제에 실패하면(한도 초과·정보 오류 등) 알림을 보내고, 예약은 그대로 둔 채 코레일톡 직접 결제를 기다립니다.
- 카드 정보는 화면·로그에 찍지 않습니다.
- **`.env`에 카드 정보가 평문으로 저장됩니다.** 내 컴퓨터에서만 쓰고, `chmod 600 .env`로 다른 사용자가 못 읽게 하세요. `.env`를 절대 커밋하거나 공유하지 마세요.
- `--auto-pay --check`로 카드 정보 **형식**은 미리 검사할 수 있습니다(실제 결제 승인은 해 봐야 압니다).
- 처음 쓸 때는 날짜가 넉넉한 표로 한 번 시험해 보고, 필요 없으면 코레일톡에서 반환하세요(출발 전 반환 수수료는 코레일 기준을 따릅니다).
- ⚠️ 자동 결제 코드는 아직 실제 카드로 결제 성공을 확인하지 못했습니다. 써 보고 결과를 이슈로 알려 주세요.

## 6. 동작 방식

1. 로그인 후, 이미 그 시간대 승차권이 **발권돼 있으면 바로 종료**합니다.
2. 그 시간대 **미결제 예약이 이미 있으면** 결제될 때까지 기다립니다.
3. 아니면 `--interval` 간격으로 조건에 맞는 KTX를 전부 조회하고, 빈자리가 있는 첫 열차를 예약합니다.
4. 예약되면 알림을 보냅니다. `--auto-pay`면 바로 카드 결제를 하고 끝납니다. 아니면(또는 결제 실패 시) 30초마다 결제 여부를 확인합니다.
   - 결제됨 → "발권 완료" 알림 후 종료
   - 결제 기한이 지나 취소됨 → 다시 3번부터 감시
5. 당일 감시라면 **지금부터 15분 뒤 출발 열차부터**만 봅니다. 감시 시간대가 다 지나면 알리고 끝납니다.

### 알림

- 터미널 출력 (항상)
- 텔레그램 (`.env`에 토큰·채팅 ID가 있을 때)
- macOS 알림 센터 + 음성 (맥에서 실행할 때)

### 오래 켜 두기

터미널을 닫아도 계속 돌리려면:

```bash
nohup python ktx_watch.py --dep 부산 --arr 서울 --date 20261020 --from 1700 --to 2100 > watch.log 2>&1 &
tail -f watch.log      # 진행 보기
```

맥은 잠자기에 들어가면 멈추므로 `caffeinate -i python ktx_watch.py ...`로 실행하세요.

## 7. 자주 묻는 것

- **로그인 실패** — `.env`의 아이디·비밀번호를 확인하세요. 휴대폰번호는 `010-1234-5678`처럼 하이픈을 넣습니다.
- **`오류: ... — 30초 대기`가 반복** — 코레일 서버가 잠시 막았거나 점검 중입니다. 조회 간격을 늘려 보세요(`--interval 5 8`).
- **SRT도 되나요?** — 아니요. 코레일(KTX)만 됩니다.
- **결제까지 자동으로 되나요?** — `--auto-pay`를 붙이면 됩니다. 기본은 예약만 합니다.
- **간편결제(카카오페이 등)도 되나요?** — 아니요. 카드번호 직접 결제만 됩니다.

## 주의

- **개인 이용 목적**으로만 쓰세요. 잡은 표를 웃돈 받고 되팔면 철도사업법 위반이 될 수 있습니다.
- 조회 간격을 너무 짧게 하면 계정이나 IP가 막힐 수 있습니다. 기본값(3~5초)보다 줄이지 않는 걸 권합니다.
- 코레일이 앱 API를 바꾸면 동작이 멈출 수 있습니다. 비공식 도구이며 코레일과 관계가 없습니다. 사용에 따른 책임은 사용자에게 있습니다.
