# korail-ktx-watch

매진된 KTX의 **취소표를 자동으로 잡아 주는** 파이썬 스크립트입니다.

원하는 구간·날짜·시간대를 정해 두면 몇 초마다 빈자리를 조회하고, 자리가 나면 **바로 예약**한 뒤 알려 줍니다.
결제는 하지 않아요. 예약이 잡히면 **코레일톡 앱에서 직접 결제**하면 됩니다(결제 기한 안에 안 하면 코레일이 자동 취소하고, 스크립트는 다시 감시를 이어 갑니다).

```
$ python ktx_watch.py --dep 부산 --arr 서울,수서 --date 20261020 --from 1700 --to 2100
로그인 성공: 홍길동
로그인 성공. 부산→서울,수서 20261020 1700~2100 출발, 어른 1명 감시 시작 (Ctrl+C로 종료)
감시 대상 9편:
  [KTX 150]  10/20 17:00~19:38  부산~서울  특실 매진, 일반실 매진 (158분)
  ...
18:02:41 #212 빈자리 없음
*** KTX 예약 성공: [KTX 158] 10/20 18:30~21:05 부산~서울 ... — 코레일톡에서 결제하세요
```

---

## 1. 준비물

- Python 3.9 이상
- 코레일 회원 계정(멤버십번호·이메일·휴대폰번호 중 하나 + 비밀번호)

## 2. 설치

```bash
git clone https://github.com/kangraemin/korail-ktx-watch.git
cd korail-ktx-watch
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 3. 계정 설정

```bash
cp .env.example .env
```

`.env`를 열어 채웁니다.

```
KORAIL_ID=1234567890          # 멤버십번호, 이메일, 휴대폰번호(010-1234-5678) 중 하나
KORAIL_PW=비밀번호

# 선택: 텔레그램으로도 알림 받기
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```

`.env`는 `.gitignore`에 들어 있어 커밋되지 않습니다.

## 4. 실행

```bash
python ktx_watch.py --dep 출발역 --arr 도착역 --date YYYYMMDD [옵션]
```

### 자주 쓰는 예

```bash
# 10월 20일 부산 → 서울 또는 수서, 17:00~21:00 출발, 1명
python ktx_watch.py --dep 부산 --arr 서울,수서 --date 20261020 --from 1700 --to 2100

# 서울 → 부산, 08:00~10:00 출발, 2명, 일반실만, 순방향 좌석
python ktx_watch.py --dep 서울 --arr 부산 --date 20261020 --from 0800 --to 1000 \
  --adults 2 --no-special --seat-dir forward

# 13:00 전에 도착하는 열차만
python ktx_watch.py --dep 서울 --arr 부산 --date 20261020 --to 1000 --arrive-before 1300
```

### 옵션

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--dep` | 출발역 (서울, 수서, 부산, 대전, 동대구 …) | 필수 |
| `--arr` | 도착역. 쉼표로 여러 개(`서울,수서`) | 필수 |
| `--date` | 출발 날짜 `YYYYMMDD` | 필수 |
| `--from` | 이 시각 **이후** 출발 `HHMM` | `0000` |
| `--to` | 이 시각 **이전** 출발 `HHMM` (포함) | `2359` |
| `--arrive-before` | 이 시각 전에 도착하는 열차만 `HHMM` | 제한 없음 |
| `--adults` | 어른 인원 | `1` |
| `--seat-dir` | 좌석 방향 `any` / `forward`(순방향) / `backward`(역방향) | `any` |
| `--no-special` | 일반실만 잡기 | 일반실 우선, 없으면 특실 |
| `--interval MIN MAX` | 조회 간격(초, 무작위) | `3 5` |

`python ktx_watch.py -h`로도 볼 수 있습니다.

## 5. 동작 방식

1. 로그인 후, 이미 그 시간대 승차권이 **발권돼 있으면 바로 종료**합니다.
2. 그 시간대 **미결제 예약이 이미 있으면** 결제될 때까지 기다립니다.
3. 아니면 `--interval` 간격으로 조건에 맞는 KTX를 전부 조회하고, 빈자리가 있는 첫 열차를 예약합니다.
4. 예약되면 알림을 보내고 30초마다 결제 여부를 확인합니다.
   - 결제됨 → "발권 완료" 알림 후 종료
   - 결제 기한이 지나 취소됨 → 다시 3번부터 감시
5. 당일 감시라면 **지금부터 15분 뒤 출발 열차부터**만 봅니다. 감시 시간대가 다 지나면 알리고 끝납니다.

### 알림

- 터미널 출력 (항상)
- 텔레그램 (`.env`에 토큰·채팅 ID가 있을 때)
- macOS 알림 센터 + 음성 (맥에서 실행할 때)

### 오래 켜 두기

터미널을 닫아도 계속 돌리려면:

```bash
nohup python ktx_watch.py --dep 부산 --arr 서울 --date 20261020 --from 1700 --to 2100 > watch.log 2>&1 &
tail -f watch.log      # 진행 보기
```

맥은 잠자기에 들어가면 멈추므로 `caffeinate -i python ktx_watch.py ...`로 실행하세요.

## 6. 자주 묻는 것

- **로그인 실패** — `.env`의 아이디·비밀번호를 확인하세요. 휴대폰번호는 `010-1234-5678`처럼 하이픈을 넣습니다.
- **`오류: ... — 30초 대기`가 반복** — 코레일 서버가 잠시 막았거나 점검 중입니다. 조회 간격을 늘려 보세요(`--interval 5 8`).
- **SRT도 되나요?** — 아니요. 코레일(KTX)만 됩니다.
- **결제까지 자동으로 되나요?** — 아니요. 예약만 잡습니다. 결제는 코레일톡에서 직접 하세요.

## 주의

- **개인 이용 목적**으로만 쓰세요. 잡은 표를 웃돈 받고 되팔면 철도사업법 위반이 될 수 있습니다.
- 조회 간격을 너무 짧게 하면 계정이나 IP가 막힐 수 있습니다. 기본값(3~5초)보다 줄이지 않는 걸 권합니다.
- 코레일이 앱 API를 바꾸면 동작이 멈출 수 있습니다. 비공식 도구이며 코레일과 관계가 없습니다. 사용에 따른 책임은 사용자에게 있습니다.
